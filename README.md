### Описание стилистики

За основу оформления взят дизайн сайта **conveer.ru** — минималистичный стиль с акцентом на чистоту и читаемость:

- **Навигация** — тёмная панель (`#1a1a1a`) с белым текстом, закреплена при скролле (`position: sticky`). Активная вкладка подсвечивается синим. В левой части — иконка «Главная», в правой — кнопка GitHub.
- **Калькулятор** — белая карточка с тенью (`box-shadow`) и тонкой рамкой. Кнопки — квадратные со скруглёнными углами. Кнопка «=» растягивается через `flex: 1` и выделена синим.
- **Страницы контента** — текст в карточках с тенью, центрирован на странице.
- **Главная** — фоновое изображение с затемняющим overlay.

### Используемые технологии

- HTML5 — семантическая разметка (`header`, `main`, `nav`)
- CSS3 — flexbox, transitions, box-shadow, псевдоклассы `:hover` и `:active`
- Шрифт: Segoe UI

### Навигация

Все страницы связаны единой навигационной панелью: Главная, Калькулятор, Об авторе, Цель работы. Текущая страница подсвечивается классом `.active`.

### Основные CSS-свойства

| Свойство | Назначение |
|----------|-----------|
| `display: flex` | Гибкая раскладка элементов |
| `position: sticky` | Закрепление навигации при скролле |
| `box-shadow` | Тень у карточек |
| `transition` | Плавная анимация при наведении |
| `border-radius` | Скругление углов кнопок и карточек |
| `background-image` | Фоновое изображение на главной |
| `user-select: none` | Запрет выделения текста на кнопках |
