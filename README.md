### Реализованные функции калькулятора

#### Базовые операции
- **Ввод цифр 0–9 и десятичной точки** — формирование числа по цифрам с защитой от повторной точки и ограничением ввода (15 символов)
- **Арифметические операции**: сложение (`+`), вычитание (`-`), умножение (`x`), деление (`/`)
- **Кнопка `=`** — вычисление результата через `switch` по сохранённой операции
- **Кнопка `C`** — полная очистка всех переменных и сброс экрана в `0`

### Принцип работы кнопки `=`

1. Пользователь вводит первое число — цифры записываются в строковую переменную `a`
2. Нажатие на оператор — значение `a` копируется в `b`, `a` очищается, оператор сохраняется в `selectedOperation`
3. Пользователь вводит второе число — цифры снова записываются в `a`
4. Нажатие `=`:
   - Проверка: `a`, `b` и `selectedOperation` должны быть заполнены
   - `parseFloat(b)` и `parseFloat(a)` преобразуют строки в числа
   - `switch(selectedOperation)` выполняет нужную арифметическую операцию
   - Результат записывается обратно в `a`, `b` очищается, `selectedOperation` сбрасывается
   - На экран выводится отформатированный результат

### Обработка событий

Для кнопок с цифрами и мгновенными операциями используется **делегирование событий** —
один обработчик `click` навешивается на контейнер `.calculator-container`, а внутри
проверяется, что нажата именно кнопка (класс `my-btn`). Для кнопок `C`, `=`, памяти
и смены цвета — отдельные обработчики через `onclick`.

### Форматирование вывода

Функция `formatOutput(val)` проверяет длину числа: если больше 10 символов,
выводит в экспоненциальной записи (`toExponential(5)`), иначе — как есть.

### Дополнительные возможности

- **Тёмная/светлая тема** — переключение через кнопку в навбаре, управляется классом `light-theme`
- **Фон с картинкой** — выбор через `<select>`, сохраняется в `localStorage`
- **Навигация** — навбар с ссылками на главную, калькулятор, об авторе, цель работы
