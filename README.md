## Введение

В рамках лабораторной работы было разработано веб-приложение на базе Express.js, реализующее REST API для управления карточками товаров (Stock). Приложение предоставляет полный набор CRUD-операций для работы с данными о конвейерах, хранящимися в JSON-файле.

## Выполненные задачи

✅ **Инициализация проекта**: Создан npm-проект с установкой Express.js и nodemon  
✅ **Базовая настройка сервера**: Настроен Express-сервер с middleware для JSON-парсинга и логирования  
✅ **Архитектура приложения**: Реализована слоистая архитектура с разделением на routes, controllers, services  
✅ **REST API**: Полностью реализованы эндпоинты для CRUD-операций с карточками товаров  
✅ **Работа с файлами**: Интеграция с JSON-файлом для хранения данных  
✅ **Статические файлы**: Настройка раздачи изображений через Express.static  
✅ **Тестирование**: Проверка работоспособности API с помощью Postman  

## Архитектура приложения

Приложение построено по принципу слоистой архитектуры:

```
example-express/
├── src/
│   ├── index.js              # Точка входа и настройка сервера
│   ├── routes/
│   │   └── stocks.js         # Маршрутизация для /stocks
│   ├── controllers/
│   │   └── stocksController.js # Обработчики запросов
│   ├── services/
│   │   ├── stocksService.js  # Бизнес-логика
│   │   └── fileService.js    # Работа с файлами
│   └── data/
│       └── stocks.json       # Хранение данных
└── static/
    └── img/                  # Статические изображения
```

Каждый слой имеет четкую ответственность:
- **Routes**: Определение маршрутов и делегирование контроллерам
- **Controllers**: Обработка HTTP-запросов и ответов
- **Services**: Бизнес-логика и работа с данными
- **Data**: Хранение данных в JSON-формате

## Реализованные эндпоинты

### Получение всех карточек
- **GET** `/stocks`
- Возвращает массив всех карточек товаров

### Получение карточки по ID
- **GET** `/stocks/:id`
- Возвращает конкретную карточку или 404, если не найдена

### Создание новой карточки
- **POST** `/stocks`
- Принимает JSON с данными карточки
- Возвращает созданную карточку с присвоенным ID

### Обновление карточки
- **PUT** `/stocks/:id`
- Обновляет существующую карточку или возвращает 404

### Удаление карточки
- **DELETE** `/stocks/:id`
- Удаляет карточку по ID или возвращает 404

## Работа с данными

Данные хранятся в файле `stocks.json` в формате массива объектов:

```json
[
  {
    "id": 1,
    "src": "/static/img/1.png",
    "title": "Ленточный конвейер",
    "text": "Универсальное решение для транспортировки сыпучих и штучных грузов на производстве."
  }
]
```

Реализован `fileService.js` для чтения/записи JSON-файла с обработкой ошибок.

## Статические файлы

Настроена раздача статических файлов через middleware:
```js
app.use('/static', express.static(path.join(__dirname, '../static')));
```

Изображения доступны по путям вида `/static/img/1.png`, что соответствует данным в JSON.
